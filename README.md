# harnas-go

A Go project used to make a harness for AI.

## Overview

harnas-go provides the foundation for an AI harness built in Go, following best practices and clean architecture.

## Getting Started

```sh
go build ./...
go test ./...
go run ./cmd/harnas version
go run ./cmd/harnas run
go run ./cmd/harnas config
```

## Project Structure

```
.
├── cmd/          # Application entrypoints
├── internal/     # Private application code
├── pkg/          # Public library code
└── ...
```
